# Halo 解锁工具

用于 **Halo: The Master Chief Collection** 的 Windows 小工具。  
可在你的电脑上备份、解锁并还原盔甲、名片等外观。

> **版本：** 1.3  
> **作者：** 木棉优纪 — [Bilibili UID 2450808](https://space.bilibili.com/2450808) · [GitHub](https://github.com/xiashizq)  
> **语言：** 默认英语，软件内可切换简体中文

---

## 功能

- 自动从 Steam 识别游戏目录
- 记住上次使用的目录
- 用表格查看解锁列表
- 修改前可备份
- 一键解锁全部
- 需要时可从备份还原
- 英语 / 中文界面

---

## 使用方法

1. 打开工具。如已安装 Steam 版，一般会自动找到游戏目录。
2. 可用 **EN / 中文** 切换语言。
3. 确认游戏目录，或点 **选择目录**。
4. 先点 **备份**。
5. 再点 **一键解锁** 并确认。
6. 若要恢复，点 **还原**。

解锁后请重启游戏（或回到主菜单），新内容才会生效。
