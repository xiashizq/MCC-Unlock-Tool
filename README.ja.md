# Halo Unlock Tool

**Halo: The Master Chief Collection** 向けの Windows ツールです。  
アーマーやネームプレートなどの見た目データを、自分の PC 上でバックアップ・解除・復元できます。

> **バージョン:** 1.3  
> **作者:** Mumian Youji（木棉优纪）— [Bilibili UID 2450808](https://space.bilibili.com/2450808) · [GitHub](https://github.com/xiashizq)  
> **言語:** 既定は英語。アプリ内で簡体字中国語に切り替え可能

---

## 機能

- Steam からゲームフォルダを自動検出
- 前回使ったフォルダを記憶
- 表でアンロック一覧を表示
- 変更前にバックアップ
- ワンクリックですべて解除
- 必要ならバックアップから復元
- 英語 / 中国語の画面

---

## 使い方

1. ツールを起動します。Steam 版ならフォルダを自動検出できることがあります。
2. 必要なら **EN / 中文** で言語を切り替えます。
3. ゲームフォルダを確認するか、**Browse** をクリックします。
4. 先に **Backup** をクリックします。
5. **Unlock All** をクリックして確認します。
6. 元に戻すときは **Restore** を使います。

解除後はゲームを再起動するかメニューに戻り、内容が反映されるようにしてください。
