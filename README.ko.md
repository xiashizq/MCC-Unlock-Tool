# Halo Unlock Tool

**Halo: The Master Chief Collection**용 Windows 도구입니다.  
갑옷, 명패 등 외형 데이터를 내 PC에서 백업·해제·복원할 수 있습니다.

> **버전:** 1.3  
> **작성자:** Mumian Youji (木棉优纪) — [Bilibili UID 2450808](https://space.bilibili.com/2450808) · [GitHub](https://github.com/xiashizq)  
> **언어:** 기본은 영어, 앱에서 간체 중국어로 전환 가능

---

## 기능

- Steam에서 게임 폴더 자동 찾기
- 마지막에 쓴 폴더 기억
- 표로 언락 목록 보기
- 변경 전 백업
- 한 번에 전체 해제
- 필요하면 백업에서 복원
- 영어 / 중국어 화면

---

## 사용 방법

1. 도구를 실행합니다. Steam 버전이면 폴더를 자동으로 찾을 수 있습니다.
2. 필요하면 **EN / 中文**으로 언어를 바꿉니다.
3. 게임 폴더를 확인하거나 **Browse**를 누릅니다.
4. 먼저 **Backup**을 누릅니다.
5. **Unlock All**을 누르고 확인합니다.
6. 되돌리려면 **Restore**를 사용합니다.

해제 후 게임을 다시 시작하거나 메뉴로 돌아가 내용이 적용되도록 하세요.
