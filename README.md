# Halo Unlock Tool

A simple Windows tool for **Halo: The Master Chief Collection**.  
Backup, unlock, and restore armor, nameplates, and other cosmetics on your PC.

> **Version:** 1.3  
> **Author:** Mumian Youji (木棉优纪) — [Bilibili UID 2450808](https://space.bilibili.com/2450808) · [GitHub](https://github.com/xiashizq)  
> **Language:** English by default, Simplified Chinese available in the app

---

## Features

- Finds the game folder from Steam automatically
- Remembers the folder you last used
- Shows your unlock list in a table
- Backup before you change anything
- Unlock all items in one click
- Restore from backup if you need to
- English / Chinese interface

---

## Usage

1. Open the tool. Steam install is detected when possible.
2. Switch language with **EN / 中文** if you want.
3. Confirm the game folder, or click **Browse**.
4. Click **Backup** first.
5. Click **Unlock All** and confirm.
6. Use **Restore** if you want to roll back.

Restart the game (or return to the menu) so the new unlocks load.
