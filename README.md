# 士官长合集解锁工具

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

一款专为《光环：士官长合集》Steam版设计的小工具，帮助玩家快速解锁所有盔甲、名片、武器和皮肤。

## 📌 功能特性

- **全自动解锁**：一键解锁游戏中所有可收集的盔甲、名片、武器和皮肤。
- **支持Steam版本**：专为Steam平台的《光环：士官长合集》优化。
- **安全可靠**：不修改游戏核心文件，仅操作本地配置，避免封号风险。
- **简单易用**：无需复杂设置，运行即生效。
- **持续更新**：随着游戏更新，本工具也适用。

## 🛠 使用方法

1. 确保你已安装并可以正常运行《光环：士官长合集》（Steam版）。
2. 按照提示选择你的游戏安装目录。
3. 点击“开始解锁”按钮，等待完成提示。
4. 启动游戏，享受全部内容！

> ⚠️ 注意：使用前建议备份，以防意外，工具支持备份。
